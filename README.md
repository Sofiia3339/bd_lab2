# Лабораторна робота №2 · NoSQL

**Варіант — система управління навчальними курсами.**

Історію проходження уроків реалізовано у двох моделях. MongoDB зберігає сесію зі спробами й відповідями в одному документі. PostgreSQL зберігає ті самі дані в трьох пов’язаних таблицях. Redis демонструє роботу зі станом активності, прогресом і рейтингом.
